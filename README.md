# Portfolio - Ngo Phuoc Thinh

A responsive developer portfolio built with React, Vite, TypeScript, Tailwind CSS, and Lucide icons. The UI uses a lightweight dev workspace style for profile, projects, and certifications.

## Tech Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS v4
- Radix UI primitives
- Lucide React

## Features

- Profile page with work experience, skills, education, honors, and activity sections.
- Projects grouped by real work, AI projects, and personal projects.
- Certifications grouped by professional, AI, and soft-skill credentials.
- Custom theme modes including light, dark, Dracula, Aqua, and Cupcake.
- Responsive layouts for desktop, tablet, and mobile.
- Hidden scrollbars with normal scroll behavior.
